PIMCO INVESTMENT UGANDA — COMPACT PORTABLE LOCAL DEMO
======================================================

Termux:
  cd ~/storage/downloads
  unzip -o pimco_investment_uganda_compact.zip -d pimco
  cd pimco
  python -m http.server 8080

Open on your Android browser:
  http://127.0.0.1:8080

Stop with CTRL+C.

The package includes an offline Font Awesome icon font. The navigation and
interface icons use genuine icon-font glyphs rather than hand-drawn SVGs.
Product images are compressed for a smaller download.

This is a front-end demo. Real deposits, withdrawals, user accounts, orders
and referral commissions require a secure backend and payment integration.
